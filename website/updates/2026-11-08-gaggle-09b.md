Title: Gaggle 0.9B: pretraining, chat, and reranking
Summary: A compact ClimbMix backbone with separate chat and relevance fine-tuning releases.
Model: 0.9b

Gaggle 0.9B is a 0.89B-parameter decoder trained from scratch with [nanochat](https://github.com/karpathy/nanochat). It uses the same tokenizer as the 3.3B Gaggle model and saw 287B tokens in one pass over [ClimbMix](https://huggingface.co/datasets/karpathy/climbmix-400b-shuffle).

At a fixed 7B-token training budget, a 32-layer model with width 1,152 and fewer value-embedding tables achieved lower validation loss and higher CORE than nanochat’s depth-20 model at roughly the same parameter count. The full pretraining run used that 32-layer shape.

## Two paths from the base checkpoint

- **Chat.** Nanochat’s two-stage recipe applies midtraining followed by supervised fine-tuning. The release includes the intermediate checkpoint. Training used no reinforcement learning.
- **Reranking.** A separate run fine-tunes the base checkpoint for pointwise relevance scoring using [RLHN-250K](https://huggingface.co/datasets/rlhn/rlhn-250K) and localized contrastive estimation.

## Evaluation

The base model scored **0.370** on nanochat’s CORE benchmark using the model card’s 500-examples-per-task setting. The reranker reached **0.632** mean nDCG@10 on TREC DL 2019–2023 and **0.533** on seven BEIR collections when reranking the top 100 BM25 candidates.
